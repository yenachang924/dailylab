# Daily Lab

Approved in chat on 2026-10-26. Home, Daily, Tools and individual Markdown entries form the first version. A daily output is working code, a short build log and a GitHub commit. Markdown is the source of truth; drafts are excluded. GitHub Actions validates, builds and deploys main to GitHub Pages.

Entries have date, title, summary, tags, optional tool and commit URL. Tools have status, description, optional demo/repository links and related entries. Actual counts derive from published content. Examples are labeled. Design: cream paper, ink typography, orange accents, numbered records.

User steering: use a cho.sh-inspired personal hub, with a compact personal introduction, recent output, 14-day activity, topic links and mini tools. No fabricated usage numbers, biography or imported personal widgets. User requested inspection before publication; keep source local until the user approves the concrete first version.
