## Input

내가 쓰려고 만든 작은 도구들이 여기저기 흩어져 있었습니다. 무엇 때문에 만들었는지, 실제로 도움이 됐는지, 어떻게 고쳤는지를 한곳에 남기고 싶었습니다.

## Output

Markdown 파일로 하루의 제작 과정을 기록하는 사이트를 시작합니다. 홈에는 최근 기록을, Daily에는 매일의 작업을, Tools에는 계속 사용하는 도구를 모읍니다.

하루의 완료 기준은 세 가지입니다.

- 작동하는 작은 코드나 기능 하나
- 입력, 결과, 검증을 담은 짧은 제작 기록
- 작업 내용을 설명하는 GitHub 커밋

## 검증

메타데이터, 날짜, 초안 제외, 공개 취소 후 페이지 제거, 저장소 하위 경로 링크를 포함한 자동 테스트 10개를 통과했습니다.

브라우저에서 홈과 기록 목록, 검색 결과 없음, 태그 필터와 모바일 화면을 확인했습니다. GitHub 자동 배포는 첫 화면 확인을 받은 뒤 연결할 예정입니다.

## 배운 점

기록하는 과정이 길어지면 제작을 멈추게 됩니다. 처음에는 짧고 구체적으로, 결과물을 다시 찾을 수 있을 만큼만 남기려 합니다.

첫 도구를 실제로 사용한 뒤, 도움이 된 점과 불편한 점을 다음 기록에 남깁니다.
